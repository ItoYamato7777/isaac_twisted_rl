# 0008 状態ボーナスを毎手払わない: 遷移で 1 回だけ払い、成功・段の変化で終了する (v3・v4 以降)

- 状態: 有効 (v3 は「段を初めて上がった手に 1 回 + 固結びで終了」、v4〜v7 は「段が変わったら +1 / −1 で終了」)
- 読むべき状況: 疎報酬・終了条件・エピソード長を変えるとき。「状態に居るだけで払う」報酬を足したくなったとき
- 最終更新: 2026-10-04

## 決定

| 版 | 疎報酬 | 終了 | 手数 |
|---|---|---|---|
| v2 / v2-R2 (採らなかった形) | `success_c1/c2/success` を条件を満たしている間**毎手** | 時間切れ・発散 | 6 |
| v3 | `ladder_bonus`: 段を**エピソード内で初めて**上がった手に +0.5 / +1.5 / +3.0 | + `knot_tied` (固結び) | 12 |
| v4〜v7 | `transition`: 段が上がる +1 / 下がる −1 / 発散 −1 / それ以外 0 | 時間切れ・発散・**段が上がる・段が下がる** (1 遷移 = 1 エピソード) | 6 |

- v3: アーカイブから C2 で始めたエピソードは、固結びの +3.0 しかもらえない。段を落として登り直しても 2 度目は払わない。整形項は成功の手でも `Φ(s')` を実際の値 (1.0) のまま払う (終端を 0 にすると、固結びを作った手に `−Φ(s)` の罰が乗るため)。
- v4: 段が上がった・下がったは、手の終わりにロープが床に落ちていて (最高点が直径の 3 倍以下) 発散していないときだけ数える ([0005](0005-measure-after-retreat.md))。段が同じなら p-data が変わっても続ける (論文より寛容)。時間切れ (6 手) は `time_out=True` なので PPO は bootstrap する。段の変化による終了は bootstrap しない。`grasp_shaping` (−0.05 × 把持距離) / `failure` (−0.1) / `held_up` (−0.1) は v3 のまま残した。
- 段の定義は [0010](0010-stage-granularity-bfs.md)、段ごとのエージェントとアーカイブは v4 README と [0009](0009-reached-state-archive.md)。

## 理由

### 毎手払う状態ボーナスは、偽の状態を悪用されやすい (v2・v2-R2 の詰まり)

v2 / v2-R2 の `success_c1/c2/success` は、条件を満たしている間**毎手**払われる。累積すると C1 に居るだけで 1 手 0.5、C2 で 2.0、C3 で 5.0 になる。γ=0.95、6 手で概算すると:

| 行動方針 | 割引収益 (概算) |
|---|---|
| 1 手目で C1 を作り、あとは維持するだけ | 約 2.9 |
| 2 手ずつで C1 → C2 → C3 (理想) | 約 8.9 |

本物の C2 の成功率が 1 手 0.3% 程度では、C1 を壊す危険を冒して C2 を狙っても期待値が見合わず、**C1 に居座るのが強い局所解**になる。v2 で偽の C2 に居座られたのも同じ仕組みで、判定の抜け道は毎手払われる報酬として繰り返し悪用される。

TWISTED-RL は「目標に到達したら +1 で**終了**」とし、そもそも居座りようがない。「ポテンシャル整形は最適方策を変えない」という保証 (Ng et al.) 自体は正しいが、この保証は状態ボーナスで決まる目的関数に対するものであり、「固結びを作る」だけを目的にした問題とは一致しない点に注意が要る。

v3 は成功で終了するので、手数を 12 に長くしても「結んだ後に居座る手」は生じない。

### 1 遷移 = 1 エピソード (v4)

v3 の最初の run (1024 環境、26 iteration、約 3.3 h) は `scratch_success` 0〜0.8%、`archive_success` 5% 前後で横ばい、方策はまだほぼランダムだった。v3 は「まっすぐなロープから固結びまでを 1 本の方策・1 エピソード (12 手) で解く」定式化のままで、TWISTED の SAC+HER ベースラインが「交差 1 は解けるが交差 2 でほぼ 0」だったのと同じ形だった。論文 (TWISTED-RL) はこれを次の 2 つで越えている。

- **エージェントを交差数ごとに分ける (C 版)。** G (1 つ) / A (移動の種類別) / C / AC のうち、C が全テストセットで最良 (3-Medium 44%、3-Hard 46%。G は 28% / 38%)。
- **1 回の位相遷移 = 1 エピソード (多段エピソード)。** 最大 M 手、位相が変わったら終了。報酬は目標に達すれば +1、変わらなければ 0、別の状態へ移れば −1。

## 検討して採らなかった案

| 案 | 扱い |
|---|---|
| 毎手払う段のボーナス (v2 / v2-R2) | 上の理由で外した |
| 論文どおりの厳密な終了 (段が同じでも p-data が変われば −1 で終了) | 既定にしない。`strict_topology=true` で切り分けとして選べる (v4 README の「切り分け」) |
| 1 つの方策を全段で共有する (論文の G 版) | 既定にしない。切り分けとして選べる (v4 README) |
