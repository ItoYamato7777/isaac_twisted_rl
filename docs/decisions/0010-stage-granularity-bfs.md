# 0010 段の粒度: 交差数でも 4 クラスのラダーでもなく、p-data グラフの BFS 距離で数える

- 状態: 有効 (v3 は整形のポテンシャル、v4〜v7 は段 `BfsPotential.stage` として使う)
- 読むべき状況: 段・ポテンシャルの定義を変えるとき。交差数でエージェントや報酬を分けたくなったとき。BFS の表の範囲 (交差 4 個) を変えるとき
- 最終更新: 2026-10-04

## 決定

- v3: ポテンシャルを `Φ = max(1 − d/3, R2 除去後のラダーの class / 3)` にする。`d` は p-data グラフ (R1 / R2 / cross) 上の、R2 除去後に固結びを含む状態までの最短手数。表は **R2 除去前**の p-data で、**交差 4 個まで**を起動時に BFS して作る (8541 状態、約 20 s)。
- v4 以降: 段 = `round(3 Φ)` (0〜3、3 = 固結び)。論文の「交差数」の代わりに、エージェント・アーカイブ・報酬を段で分ける。

| 段 | 含む状態 | エージェント (v4) |
|---|---|---|
| 0 | 自明 (まっすぐ・曲がっただけ) | π0 |
| 1 | 輪 1 つ・独立したねじれ 2 つ・偽の C2 | π1 |
| 2 | 本物の C2・**cover 後** (`1U4+_2O5+_3O6-_4O1+_5U2+_6U3-` など) | π2 |
| 3 | 固結び (ゴール) | — |

値は v3 の BFS 表そのもので、新しく数え直した状態は無い (`tests/test_knot_graph.py`)。BFS の表の中身、R2 除去前・交差 4 個にした理由、ラダーとの max を取る理由は `kt/common/topology/knot_graph.py` の docstring にある。

## 理由

### 4 クラスのラダーは粗く、cover の手を評価できない

pick&place では**掴んだ区間が必ず上に置かれる** (`test_r2_reduce.py` の幾何で確認)。

- 先端側を運んで輪を作る (R1) と、交差 A で先端側が上 (O) になる。
- 続けて先端を輪へ差し込む (Cross) と、先端はまた上 (O) になる。
- 結果は **OO になり、R2 で交差 0 に戻る**。本物の C2 (OU) にするには、**輪の側を掴んで先端の上に被せる**必要がある。

Yan2020 の固結びの手順 C(2,0,1) も「区間 2 (輪) を区間 0 (先端) の上へ」であり、同じことを言っている。ゲート 1 の台本でも、固結びの「下」は cover のように輪の側を動かしてしか作れなかった。

v2-R2 のラダーは「次の手が打てる C1」と「打てない C1」に同じ Φ=0.35 と `success_c1` +0.5 を払う。TWISTED / TWISTED-RL の高レベル計画は R1 の**種類** (sign・left・over first) まで区別した p-data で経路を決める。Yan2020 は、次のプリミティブの価値を前のプリミティブの報酬に使って「次の手が打てる幾何」を学ばせている。そこで**段の粒度を p-data 単位に細かくする**方向にした (`paper/Report_Paper.md` §5.4、§7 P1-3)。

ゲート 1 で、cover の直後は多くの場合 edge A のたるみが尻尾を 2 回またいだ `1U4+_2O5+_3O6-_4O1+_5U2+_6U3-` になると分かった。これは R2 除去すると C1 (`1U2+_2O1+`) と同じになるが、この状態から tuck で約 7 割が固結びになる。v2-R2 の報酬では「cover を打っても何も起きていない」ように見える。v3 の BFS 距離ポテンシャルで、この状態を段として数えるようにした。

### 生の交差数を段にしない (v4)

cover 後 (生 3・R2 除去後 1) や偽の C2 (生 3) が、固結びまでの近さと合わないため。

### 分かった限界

輪 1 つの 4 通りはどれも d = 2 で、`paper/Report_Paper.md` §5.4 の「次の手が打てる C1 / 打てない C1」の差は p-data には現れない (差は幾何のほうにある)。

## 検討して採らなかった案

| 案 | 採らなかった理由 |
|---|---|
| R2 除去後の p-data を交差 3 個まで BFS (Report の案) | 固結びに届く p-data は 13 個 (自明・輪 4・C2 4・固結び 4) だけで、経路上ではラダーと完全に同じ値だった |
| 「掴んだ側が上になる」制約をグラフの辺に入れる (Report §7 P1-3) | この制約はどちらの区間を掴むかを決めるだけで、位相の辺は減らない (先端が下になる cross も cover で実行できる) |
| BFS の値だけを使う (max を取らない) | 交差 4 個で打ち切るため、4 交差の途中状態や尻尾に余分な輪が付いた状態が「届かない」(0) になり、ラダーより下がって「ねじれを足すと値が上がる」逆転が生じる |
| 生の交差数で段を分ける (論文どおり) | 上の理由 |
