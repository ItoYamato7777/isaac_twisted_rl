# 0013 学習のロープは `Knot` (PhysX の剛体鎖 28 リンク・1.14 m)

- 状態: 有効 (v3〜v7 の学習。摩擦の値 2.0 か 0.5 かは未決)
- 読むべき状況: ロープのプリセット・紐モデル (表現) を替えたくなったとき。実機へ持っていく紐モデルを選ぶとき。`Knot` の物性を確かめたいとき
- 最終更新: 2026-10-04

## 決定

- v3 以降の学習には `Knot` (`rope_specs.py` の `knot` プリセット) を使う。`twist` と**材料・太さ・リンク長が同じ**で、28 リンクに延ばしただけ。
- 紐モデルの比較 (rope study、2026-10-02〜03) の結論: **表現としては、PhysX の剛体鎖 (28 リンク、`Art28` 系) を、実機の検証へ持っていく最有力として推す。摩擦の値 (`Art28` の 2.0 か `Art28LowMu` の 0.5 か) は、今回の評価では決めきれない。** XPBD の Cosserat 棒は今回は推さないが、学習の崩れを直したうえで、もう一度比べる価値が最も高い候補として残す。

## 理由

### 長さが決め手 (ゲート 1、2026-09-27)

固結びは、本体 ~8 / 輪 ~12 / 尻尾 ~8 リンクを使う。20 リンクの `twist` (0.82 m) では、tuck の時点で輪の中の尻尾が 2〜3 リンクしか残らない。持ち上げると edge A の下から抜けて C1 に戻ってしまう。グリッパーが輪の片側だけを掴めるよう輪の径は 15 cm 前後要る (開いた指は掴む軸から ±4 cm を占める) (`rope_specs.KNOT_NUM_LINKS` の docstring)。

`knot` は、`twist` と材料・太さを同じにして 28 リンクに延ばしただけ。1 リンクの物理 (質量・慣性・関節ゲイン・把持力) が同じなので、把持・「離すと付いてくる」対策 ([0004](0004-release-follow-physics.md))・発散しにくさをそのまま引き継ぐ。細く・細かくした `fine` は結び目の分解能では有利だが、慣性が小さく発散しやすい。

台本 (`overhand_script.py`、±25% 揺らし、128 環境) の固結び成功率は `twist` で最高 23/128 (18%)、`knot` で 122/128 (95%、発散 0) (ゲート 1。詳細は [`docs/experiments/2026-09-27_gate1.md`](../experiments/2026-09-27_gate1.md))。`knot` を速く運ぶと発散するので、尺を延ばした ([0014](0014-gate1-wiring-for-knot.md))。

### 剛体鎖を推す理由 (rope study §10.2)

選定に使う量は、他のモデル・摂動の下での成功率の平均と最悪値 (同報告 §7.4)。

1. **最悪値で剛体鎖が明らかに上**: `Art28` 19.1 ± 2.5%、`Art28LowMu` 18.0 ± 2.4%、v4 の `Knot` (同じ紐の別の run) 20.7 ± 2.5% に対し、XPBD の方策は最良のチェックポイントで選んでも 0〜5%。差は誤差より十分大きい。実機の紐はどのモデルとも違うので、「他の紐で全く結べなくなることがある方策」を生むモデルは実機で外れる危険が大きい、と判断した。
2. **平均は誤差の範囲で並ぶ**: 他の 5 モデルの平均は `Art28` 32.3%、v4 の `Knot` 31.3%、`XpbdC28` (it50) 29.1%、`Art28LowMu` 27.3%。全条件の平均は `XpbdC28` (it50) が 39.2% で最も高いが、2 つの条件 (80〜86%) に偏った値で、最悪 2.3% と合わせると頑健とは言えない。平均だけでは順位を断定しない。
3. **2 つの剛体鎖の間は断定しない**: 他モデルの平均は `Art28` が 5 ポイント上 (32.3 対 27.3、標準誤差 1.8)、最悪値は同等 (19.1 対 18.0)。一方、実物の範囲の摩擦の条件では `Art28LowMu` の方策が上 (24.6 対 19.1)。`Art28LowMu` は 100 iteration でまだ伸びており (it50 7.6% → it99 24.6%)、学習量を揃えた比較になっていない。seed も 1 本。
4. **sim で最良のモデルをそのまま結論にしていない**: 自分のモデルでの成功率は `Art28` (38.3%) が最も高いが、それは結論の根拠にしていない。`Art28` は摩擦が実物の 3〜10 倍で、**その方策は低摩擦の紐で成功率が半分になる** (38.3 → 19.1%)。実機の机と紐は低摩擦側なので、`Art28` の自分のモデルでの成功率は実機の期待値として楽観的すぎる。

### 剛体鎖の有利・不利 (同 §10.3)

- 有利: 剛体の指と剛体のカプセルの摩擦把持は、実機の把持と同じ仕組みで、把持・保持・結び目の保持の試験でどれも 98〜100%。伸びない。転移の最悪値が最も高い (他の紐に変わっても 2 割は結べる方策になる)。Isaac Lab の標準の資産で保守が楽。剛体カプセル鎖は較正すれば実機に合う例がある (Real2Sim2Real、Wiggle and Go!)。
- 不利: **数値の発散** (ランダムな手の 3〜10%、chain 評価で 16〜19%) は実機に無い現象で、学習を歪める可能性がある (v5 の「高く離す」)。4 cm の離散化で実効の曲げ剛性が名目の 0.43 倍なので、実機で測った EI を入れても実物より柔らかい紐になる。摩擦への依存が大きい。曲げ剛性 x2 (硬い紐) で成功率が 3〜4 割落ちる。学習が遅い (単独の GPU で 87 手/s) ので、ドメインランダム化・複数 seed の試行に時間がかかる。

## 検討して採らなかった案

| 案 | 採らなかった理由 (rope study §10.3) |
|---|---|
| `twist` (20 リンク) のまま | 長さが足りず、台本でも固結びがほぼ結べない (上) |
| XPBD Cosserat (`XpbdC28` / `XpbdC56` / `XpbdC28LowMu`) | 物理では、発散 0、片持ち梁で理論と一致、材料定数がそのまま入る、`XpbdC28LowMu` は台本で最もよく結べる (79%)、学習が約 11 倍速い、と最も有利。不利なのは、(1) v4 の PPO で段 0 の方策が崩れる (全 4 モデル・2 seed で再現、原因未解決)、(2) 方策が剛体鎖・質点-ばねにほとんど転移しない、(3) 把持の連成が近似 (直方体の指、一方向)、(4) 同じ μ でも PhysX と摩擦の挙動が違う、(5) 自前のソルバの保守。(1) が直れば結論が変わりうる |
| `XpbdMS28` | 実機で測った EI を入れる方法が無く、学習・転移とも最も低い |
| `Art56` (細かい剛体鎖) | 発散が多すぎる (反復 32 でも 37%) |
| `Fem` | 剛体の指で保持できない (保持 0%)、較正なし |

結論が変わりうる条件 (同 §10.4):

- XPBD の段 0 の崩れが直り、XPBD の方策の転移の最悪値が剛体鎖と同等以上になった場合 → XPBD Cosserat (特に `XpbdC28LowMu`) を推す。学習の速さと物理の妥当性の分だけ有利。
- 実機の紐と机の摩擦が 1 を超える (ゴム引きの机など) 場合 → `Art28` の摩擦設定の弱点は小さくなる。
- 実機の段 2 の試験 (同 §11) で、剛体鎖の中心線の誤差が XPBD より大きいと分かった場合 → 物理の妥当性を優先して XPBD の学習の改善に投資する。
