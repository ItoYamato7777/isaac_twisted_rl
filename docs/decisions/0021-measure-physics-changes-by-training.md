# 0021 物性 (物理の設定) を変えるときは、計測だけでなく学習と chain 評価で確かめる

- 状態: 有効 (v5 の教訓。物理・ロープ・把持の設定を変えるすべての版に適用)
- 読むべき状況: 発散対策などで物理の設定 (めり込み解消速度・離す高さ・ソルバの反復・接触の設定・ロープのプリセット) を変えるとき。`demos/divergence_bench.py` やゲート 1 の台本の再生の結果だけで採否を決めそうになったとき
- 最終更新: 2026-10-04

## 決定

- 物理の設定の変更は、学習済みの方策・乱数の手・台本での計測 (発散率・把持・台本の固結び) で良くても、**ゼロからの学習で効果を確かめるまで採用を確定しない**。
- 学習での確認は、学習ログの段ごとの成功率や `chain_est` ではなく、**chain 評価** (`scripts/rsl_rl/eval_chain.py`。定義は [`docs/system/evaluation.md`](../system/evaluation.md)) で行い、シード差 (v6 の 2 シードで 15〜19 ポイント) と比べる。
- 計測は、学習の前に悪い設定をふるい落とすためのゲートとして使う (手順は skill `physics-check`)。

## 理由

v5 の発散対策で、計測と学習の結果が逆になった。

| 段階 | めり込み解消速度 0.4 m/s (v5) の効果 | 出典 |
|---|---|---|
| 計測 (学習済みの v3 方策 `model_150.pt`、1024 環境 × 24 手) | 1 手あたりの発散 1.88% → 0.44%、固結びで終わったエピソード 41.9% → 49.1% (A を含む) | [`docs/experiments/2026-10-01_v5_divergence.md`](../experiments/2026-10-01_v5_divergence.md) §3 |
| 計測 (ゲート 1 の台本の再生、256 環境 × 種 2 通り) | 固結び 53.1% → 59.0%、発散 8.2% → 1.4% (A を含む) | 同 §4 |
| 学習 (seed 42、4096 環境、v4 との比較) | 段 2 -> 固結び (tuck) を学べず、chain 評価は v4 の 1/4 以下 (iteration 100 で v5 9.6%、v4 41.6%) | [`docs/experiments/2026-10-01_v4-v6_overnight_detail.md`](../experiments/2026-10-01_v4-v6_overnight_detail.md) §3.1 |
| 切り分け (v6 に 1 つずつ v4 の値を戻す、seed 42、iteration 70) | 学習ログの段 2 を止めていたのはめり込み解消速度で、離す高さではなかった。0.4 m/s では学習前から段 0 の時間切れが多い (29%、0.96 m/s では 5%) | 同 追記 |
| 切り分けの chain 評価 | 0.96 m/s に戻すと学習ログでは段 2 を学べたが、chain 評価の発散も v4 並み (17%) に戻り、固結び率は v6 と差が出なかった | 同 追記 |

- 計測は学習済みの方策や台本 (正確な手を知っている) で行う。ゼロから学ぶ方策の探索で当たる手とは分布が違う。
- 物性は学習の初期から状態の分布を変える (段 0 の時間切れの差は学習前からあった)。
- 学習ログの段ごとの成功率と `chain_est` は、本番の成功率を表さなかった (v6 では学習中の段 2 の成功 5% でも chain 評価は 23〜38%)。そのため学習での確認も chain 評価で行う。

v5 README の文言 (転記元): 「上の「試した対策」の表は学習済みの v3 方策 (`model_150.pt`) で測ったもので、0.4 m/s は固結びを増やしていた。**学習済みの方策での計測と、ゼロからの学習での効果は一致しなかった。** 物性を変えるときは学習で確かめること。」

## 検討して採らなかった案

| 案 | 採らなかった理由 |
|---|---|
| 計測 (発散率・把持・台本の固結び) だけで採否を決める | v5 で逆の結論になった (上の表) |
| 学習ログの段ごとの成功率・`chain_est` で学習の効果を判断する | chain 評価の良し悪しを予測しなかった (overnight の §4.5 と追記の「わかったこと」3) |
| 1 シードの学習で決める | シード差が 15〜19 ポイントあり、1 シードどうしの 10〜15 ポイントの差は判別できない (overnight の追記の「わかったこと」4) |
