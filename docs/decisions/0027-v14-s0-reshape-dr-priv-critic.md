# 0027 v14 は段 0 の形を変えた手の保存・ロープの物理の DR・critic の特権観測を入れる

- 状態: 有効 (v14 以降)
- 読むべき状況: v14 を学習・評価するとき。段 0 のアーカイブの中身、物理のドメインランダム化、critic にだけ渡す観測を扱うとき
- 最終更新: 2026-10-14

## 決定

v14 = v13 + 次の 3 つ (ユーザーの指示、2026-10-14)。1 版 1 変数から外れる (ユーザーが了承済み) 代わりに、3 つとも Hydra の上書きで個別に切れる。切り分けの run は、結果が悪いときだけ回す。

1. **段 0 の保存の規則 `stage_up_s0_reshape`**: `stage_up` (v12) で保存する行に、段 0 の方策が交差なしのまま形を変えた手の後の形を足す。1 エピソードにつき 1 回まで。
   - 条件: 床に落ちていて発散していない・手の前後とも段 0・手の前後とも交差 0 個 (R2 除去の前)・形の変化 ≥ `s0_min_change` = 0.02 m・この env のこのエピソードでまだ保存していない。
   - 形の変化は、手の前後のリンクの xy を 2 次元の剛体の位置合わせ (重心と回転。鏡映なし) をした後のずれの RMS (`state_archive.rigid_aligned_rms`)。
   - 切るとき: `env.rewards.record_stage_archive.params.save_on=stage_up`。
2. **ロープの物理の DR** (`mdp.RandomizeRopePhysics`): reset のたびに env ごとに 6 軸の倍率を引き直す。減衰比 ζ は公称値の ×1.0〜×2、ほかの 5 軸は ×0.5〜×2 (対数一様。ζ の下限の理由は下の「ロープの物理の DR と critic の特権観測」)。
   - 曲げ剛性・捩り剛性・減衰比 (ζ。減衰 = 公称 × sqrt(s_k · s_m) × s_ζ)・質量 (慣性も同じ倍率)・ロープの摩擦・指の摩擦。
   - 摩擦の公称値はロープ・指とも 0.5 (下の「摩擦の公称値」)。μ は 0.25〜1.0。
   - 切るとき: `env.events.rope_dr.params.enabled=false`。
3. **critic の特権観測**: 引いた倍率を [−1, 1] に正規化した 6 次元 (`mdp.rope_physics_params`) を critic だけに入れる。`obs_groups.critic = ["rope_params", "policy"]` (203 次元)。actor の観測は v13 と同じ 197 次元。
   - 切るとき: `agent.obs_groups.critic=[policy]`。

- Play (chain 評価) は DR を切る (公称の物理)。v13 と同じ物理で比べるため。DR を付けた評価は `env.events.rope_dr.params.enabled=true`。
- 学習: seed 43 / 44 を 0 から iteration 300 まで。比べる相手は v13 (同じ seed)。
- ロープの直径と長さの DR は v16 に分ける (当初は v15。2026-10-16 に bootstrap の修正と入れ替えた) (ユーザーの指示、2026-10-14。範囲は ×0.8〜×1.25)。PhysX は実行中にカプセルの形を変えられないので、直径・長さの違う USD を起動時に env ごとに割り当てる方式になり、直径と長さを 1 つの数として持つ箇所 (行動の座標・床に落ちた判定・指のゲインなど) を env ごとの値に直す必要がある。

## 理由

### 段 0 の保存の規則

- v12・v13 の段 0 のアーカイブには学習中に何も入らない。段 0 から始まる形は、まっすぐなロープ (確率 0.5) と、台本の 128 形 (交差 0 個、関節角の平均絶対値 約 0.08 rad で、ほぼまっすぐ) だけ。段 0 の方策は、まっすぐに近い形からしか練習できない。
- 段 0 の方策が打った手のうち、交差を作らずに形を変えた手の後の形は、段 0 の方策が出会いうる「様々な形」になる。
- 交差のある段 0 の形 (行き止まり) は入れない。v7 の延長で段 0 に溜まって段 0 を壊したのはこの形だった ([v11 の記録](../experiments/2026-10-07_v11_dead-end-stages.md))。交差 0 個なら位相は自明で、抜け出せない形にはならない。
- v12 が断った「方策の出力が自分の訓練に戻るループ」は、段 0 で再び開く。1 エピソード 1 回までにして入る量を絞る (段 0 のエピソードは約 600 / iteration で、容量 16384 は数十 iteration で入れ替わる)。
- 形の変化を剛体の位置合わせの後で測るのは、ロープ全体を引きずる・回すだけの手を「形を変えた」と数えないため。0.02 m (直径 1 本) は仮の値で、スモークテストで `s0_change_mean` の分布を見て決め直す。

### ロープの物理の DR と critic の特権観測

- 物理の値の違いに強い方策にする。剛性・減衰・質量・摩擦はどれも、実機との差が大きく、方策が掴む・置く・離すの結果を左右する。
- Isaac Lab の randomize 系の関数は使わない。引いた値を残さない (critic に渡せない)、要素ごとに独立に引く、剛性はロープに actuator が無いので `randomize_actuator_gains` が何もしない。自前のイベント項で env ごとに 1 組を引いてキャッシュする。
- 減衰は臨界減衰に対する比 ζ を独立な軸にする。剛性と質量だけを振ると、USD の減衰 (ζ = 1) のままでは比が勝手に変わり、剛性の軸と減衰の軸の効果が混ざる。
- **ζ の下限は ×1.0 (臨界減衰)。** 物理のゲートで、ζ の小さい 3 分の 1 (平均 ×0.64) の 1 手あたりの発散が 7.06% (公称 2.90% の 2.4 倍)、ζ ×0.5 を含む端の組は 2.7〜3.9 倍だった ([ゲートの記録](../experiments/2026-10-14_v14_physics-gate.md))。発散した手は学習の信号を汚すので、臨界減衰より下げない (ユーザーの判断、2026-10-15)。ζ の上側 (×2) は ×1.0〜×2 の範囲に残す。公称の物理は ζ の範囲の端になる (critic の特権観測では −1)。
- critic にだけ物理を教える (asymmetric actor-critic)。actor は物理を観測できないので、DR を入れると同じ観測から違う結果が出て、価値の見積りの分散が増える。critic が物理を知っていればそれを下げられる。actor は実機で物理を知らなくても動く。
- 特権観測を critic の観測の **先** に置くのは、`StageGatedActorCritic` が critic の観測でも最後の 4 列 (段の one-hot) で頭を選ぶため。
- 床は全 env で 1 枚なので振らない。握る力 (指のゲイン 1508 N/m) は公称の質量に合わせたまま。質量 ×2 で握れるかは物理のゲートで見る。

### 摩擦の公称値

v14 の実装のときに、ロープと指の摩擦が文書の値 (ロープ 2.0、指 4.0 の `max` 合成) と違うと分かった ([2026-10-14_friction-binding](../experiments/2026-10-14_friction-binding.md))。

- ロープは μ = 0.5 (PhysX の既定の材質)。USD の材質の bind 先が `Material` でなく `Scope` の prim で、PhysX が無視する。
- 指も約 0.5・average 合成 (起動後の bind が PhysX に届いていない。読み戻しと物理の試験からの推測)。

v0〜v13 はすべてこの物理で学習した。既存の版の挙動は変えない。DR の倍率は PhysX から起動時に読んだ値に掛け、範囲は実際の公称値を中心にする (ユーザーの判断、2026-10-14)。こうすると v13 と同じ物理が分布に入り (ζ 以外の 5 軸では真ん中、ζ では端)、公称の物理での chain 評価で v13 と比べられる。

### 見込みの弱点

- **アーカイブに物理を残さない。** ある物理で保存した形を別の物理の env に書き戻す。剛いロープは最初の手の間にまっすぐへ戻ろうとし、摩擦の低いロープは滑る。chain 評価で別の物理に出会うのと同じと見て受け入れる。`fail_s{k}` と `restore_mismatch` で見張る。
- DR で学習が遅くなり、公称の物理での chain 評価が v13 を下回るかもしれない (頑健性と公称での性能の交換)。3 つを同時に入れるので、悪いときにどれが効いたかは切り分けの run が要る。
- 段 0 の新しい形は、段 0 の方策が作れる形に限られる。方策が同じ型の手を繰り返せば、多様さは増えない。
- `eval_search.py` は状態を別の env に写すので、写し先の env の物理で V(s) を計算する (Play の既定は公称の物理)。

## 外れたら仮説が誤りと言える予想

1. 段 0 の保存の規則が効く: 段 0 のアーカイブに交差の無い形が溜まり (`arc_size_s0` が 128 から増える)、学習ログの `timeout_s0` が 2 シードとも 0.1 を超えない。
2. 公称の物理での chain 評価が v13 を下回らない: 2 シードの平均で、it100・it300 とも v13 から 5 ポイント以上は下がらない。
3. DR が頑健性を上げる: DR を付けた chain 評価 (`enabled=true`) で、公称からの下がり幅が v14 の方が v13 より小さい。

1 が外れたら段 0 のループが開いている (1 エピソード 1 回では足りない)。2 が外れて 3 が当たったら頑健性と性能の交換で、切り分けの run (DR を切る・特権観測を切る) で原因を探す。

## 検討して採らなかった案

| 案 | 採らなかった理由 |
|---|---|
| 段 0 の形を変えた手を毎回保存する | v12 が断ったループが段 0 で開く。1 エピソード 1 回に絞る |
| 交差のある段 0 の形も保存する | v7 の延長で段 0 を壊した行き止まりの形が入る |
| 形の変化を関節角の差で測る | 関節角の差は位置合わせの不要な量だが、リンクの位置の変化と単位が違い、閾値の意味 (直径 1 本) が付けにくい |
| Isaac Lab の `randomize_rigid_body_mass`・`randomize_rigid_body_material` を使う | 引いた値を残さず要素ごとに独立に引く。critic に渡せない |
| 物理を actor にも入れる | 実機では物理を観測できない |
| アーカイブに物理を一緒に残し、復元のときに同じ物理を書く | 保存の形式とアーカイブのファイルが変わり、既存の初期アーカイブと混ぜられない。chain 評価では物理は選べないので、別の物理への書き戻しは評価の条件に近い |
| 摩擦を文書どおり (2.0 / 4.0) に直してから振る | 物理を変えると v13 と公称の物理で比べられない。直すなら別の版にする |
| 直径・長さも v14 で振る | 変更の規模が大きく、v14 の切り分けを汚す。別の版 (v16) に分ける |
