# 0032 このリポジトリは Sim の学習にとどめ、Sim でできることを実機でもできる方策を作る。初期状態はまっすぐなロープから始め、広げるのはユーザーの指示のとき

- 状態: 有効 (2026-10-19 にユーザーが方針として決めた)
- 読むべき状況: 最終的な目標を確かめたいとき。物理・ロープ・観測・評価の初期状態を変える案の採否を決めるとき。実機の側 (`hiro_knot`) との境目を確かめたいとき
- 最終更新: 2026-10-19

## 決定

1. **最終的な目標は、実機のロボットがロープを固結びにすること。** このリポジトリ (`isaac_twisted_rl`) は Isaac Lab の Sim での強化学習にとどめる。ここで得た方策 (チェックポイント) を、別のリポジトリ `hiro_knot` が実機で使う。実機の実験・撮影・実機側のコードはこのリポジトリに持たない (実機の動画の置き場所と命名だけは [0031](0031-eval-chain-video.md) にある)。
2. **実機の達成条件は「Sim でできることを実機でもできる」こと。** Sim で結べる状況なら、実機でも結べるようにしたい。たとえば Sim で学習中に出ていない場面・形・初期状態でも結べるなら、実機でも同程度の汎化があることを求める。実機の成功率や試行回数の数値の目標は決めていない (未決)。
3. **したがって、Sim の中では「Sim2Real のギャップに強い方策」を設計の判断軸にする。** 同じ Sim の成功率でも、Sim の物理の細部に依存した方策よりも、物理・寸法・初期状態の違いに耐える方策を採る。
   - 物理の DR ([0027](0027-v14-s0-reshape-dr-priv-critic.md))、ロープの長さの DR ([0029](0029-v16-rope-size-dr.md))、critic にだけ物理を渡す特権観測、actor に実機で観測できないものを入れないこと。
   - 紐モデルの選定で転移の最悪値を見たこと ([0013](0013-rope-knot.md))。
4. **評価の初期状態は、今はまっすぐなロープ。** chain 評価の `knot` はまっすぐなロープから 18 手で固結びに達した割合で、これが版の比較の指標。実機の成功率の予測ではない (Sim の指標)。
5. **初期状態を、交差なしの様々な形に広げたい。ただし広げる時期はユーザーが決める。** まっすぐな状態の成功率が十分に高くなったとき、またはこれ以上直す内容が無くなったときに、ユーザーが明示的に、初期状態をより難しく複雑にする実装を指示する。それまでは Claude が、評価の初期状態を変える・難しい初期状態の評価を主指標にする・そのための版を提案して始める、ことをしない (提案を述べるのはよい)。
   - 学習の初期状態にはすでに、まっすぐなロープ (確率 0.5)・台本の 128 形・v14 以降の段 0 で交差なしのまま形を変えた手の後の形が入る。これは段 0 の方策に様々な形から練習させる手段で、評価の初期状態は変えていない。

## 理由

- 実機は Sim と物理・寸法・初期状態が違う。実機の実験は時間がかかり、版ごとに回せない。Sim の中で違いへの頑健さを作り込む必要がある。
- 実機のロープは完全にはまっすぐにならない。評価の初期状態をまっすぐなロープに固定したままでは、「Sim でできることは実機でもできる」の確認には足りなくなる。ただし、まっすぐな状態の成功率がまだ低いうちに初期状態を広げると、版どうしの比較 (v7〜v16 の chain 評価) の意味が変わり、何が効いたかが分からなくなる。そのため、広げる時期はユーザーが決める。
- 方針を判断の軸として 1 か所に置くことで、物理・ロープ・観測を変える案を採るかどうかを、毎回同じ基準で決められる。

## 検討して採らなかった案

| 案 | 採らない理由 |
|---|---|
| 目的を「交差なしのロープから結ぶ」に書き換える | 評価の初期状態が今はまっすぐなロープで、書いた目的と測っているものが食い違う。広げるときに評価の定義と一緒に変える (決定 5) |
| 今から評価の初期状態を交差なしの様々な形に広げる | 今の比較の基準 (v7〜v16) が使えなくなる。まっすぐな状態の成功率が上がってからにする (ユーザー、2026-10-19) |
| このリポジトリに実機の実験・達成条件の判定を持つ | 実機は `hiro_knot` の役割。このリポジトリは方策を作るところまで |

## 広げるときに決めること (ユーザーが指示したとき)

- chain 評価の始まりを、どんな分布の交差なしの形にするか (ほぼまっすぐな形から、大きく曲がった形・輪になりかけた形まで、どの範囲か)。
- 版どうしの比較の基準をどうするか。まっすぐなロープからの `knot` を併記して残すか。
- 学習の初期状態の分布を評価に合わせるか。
