## 結果

### 実測 (v2 の `model_700.pt` を v2-R2 の Play 環境で再生, 9 環境 x 約 11 エピソード)

| 手 | p-data (R2 除去前) | 判定 (v2) | R2 除去後 |
|---|---|---|---|
| 1〜2 | `1O2+_2U1+` | class 1 | class 1 |
| 3〜6 | `1O4+_2O5-_3O6+_4U1+_5U2-_6U3+` | **class 2** | **class 1** `1O2+_2U1+` |

全環境・全エピソードで同じ動きだった (決定論的方策)。v2 の方策は
**輪を作り、3 手目で先端を輪の下に丸ごと通して、そのまま居座る** ことを
学習しており、これが `success_c2` (+1.5) と整形報酬 (0.35 -> 0.70) を
毎手稼いでいた。Play で「先端が輪に入っていない」と見えたのはこのため。

ランダム方策 (学習開始直後) でも `raw_c2` 0.029 に対して `r2_c2` は 0.000 で、
**v2 の C2 発火はほとんどが偽物だった** (16 環境 x 2 iteration の smoke test)。
ただし標本を増やすと、本物の C2 も 1 手あたり約 0.3% は起きている
(1024 環境の学習ログ。Report §5.1。Report は今の `paper/Report_Paper.md`)。

## 結論

- 分かった: v2 の方策は、R2 除去後には C1 にすぎない 3 交差状態 (偽の C2) に居座り、`success_c2` と整形報酬を毎手稼いでいた (9 環境・決定論的方策で全エピソード同じ)。ランダム方策でも v2 の C2 発火はほとんどが偽物だった (16 環境 x 2 iteration)。
- 推測: 本物の C2 は 1 手あたり約 0.3% しか起きず、ランダム探索では C2 に届きにくい (v2-R2 README の「この版で解決しないこと」。この見積りが v3 の動機になった)。
- 未確認: 「本物の C2 は 1 手あたり約 0.3%」の根拠の run は「1024 環境の学習ログ」とだけ書かれていて、どの run かは特定できない (`docs/history/refactor/audit/B_2.md` の B-110。`logs/rsl_rl/knot_tying_v2_r2/` の run は `2026-09-26_15-57-53` の 1 つだけ)。
