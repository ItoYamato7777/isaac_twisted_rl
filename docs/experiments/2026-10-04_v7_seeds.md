## 結論

- 分かった:
  1. **iteration 100 の chain 評価で、v7 の 2 シード (53.7% / 47.3%) はどちらも v6 の 2 シード (37.9% / 22.9%) と v4 (41.6%) を上回った。** 平均の差は v6 に対して約 20 ポイントで、v6 のシード差 (15 ポイント) より大きい。v7 の低いほうと v6 の高いほうの差は 9.4 ポイント (標準誤差は各 2 ポイント前後)。
  2. **iteration 70 では差が見えない。** v7 の 3 シードの平均 31.6% と v6 の 2 シードの平均 25.6% の差は、シード差 (18〜19 ポイント) に埋もれる。2026-10-02 の「chain 評価では v7 の優位が見えない」は iteration 70 だけを見た結果で、iteration 100 では成り立たない。
  3. **iteration 70 -> 100 の伸びは v7 が大きい** (+13 / +24 ポイント。v6 は +3 / +7、v4 は +12)。
  4. **発散は v7 で 12〜14% (iteration 100)。** v6 (5〜7%) より多く、v4 (18%) より少ない。発散しなかったエピソードの中の固結びは v7 が 53〜62% で最も高い。
  5. 学習ログの形 (段 2 の成功が伸び、時間切れが増えない) は v7 の 3 シードで再現した (代理の指標)。
- 推測:
  - v7 の優位は、段 2 -> 固結びを学べること (めり込み解消速度 0.96 m/s) から来ていて、v6 の発散の少なさの利点を上回った。学習ログの段 2 の差と chain 評価の段 3 到達の差が同じ向きであることからの推測で、因果は確かめていない。
  - v7 は iteration 100 でもまだ伸びている (70 -> 100 の伸びと `chain_est` の上昇から)。頭打ちの位置は分からない。
- 未確認:
  - **シードが揃っていない。** iteration 100 の比較は v7 (43 / 44) と v6 (42 / 43) の各 2 シードで、v7 seed 42 (`abl_depB`) は iteration 70 で止めた run。同じシード 43 どうしでは v7 53.7% 対 v6 22.9%。
  - **学習の GPU の配置が違う。** v7 は GPU 1 枚に 1 本、v6・v4 は 2 本。同じ iteration で比べているが、配置で iteration あたりの学習の進みが変わらないかは確かめていない (同じアルゴリズム・環境数なので変わらないと見込むが、PhysX の GPU の非決定性はある)。
  - 確率的な方策での chain 評価、評価 seed を変えたときの値。
