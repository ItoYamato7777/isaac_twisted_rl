# v12 (v7 + アーカイブに段が上がった手の後の形だけを保存) の学習 (seed 43 / 44、iteration 300) と chain 評価 (2026-10-13)

- 状態: 凍結
- 読むべき状況: v12 の結果を v7・v11・v13 と比べるとき。chain 評価が it70〜100 の後に下がる問題の経緯を知るとき

## 目的と仮説

v11 s43 の延長では、到達状態アーカイブが毎手の形を保存するので、方策の抜け出せない形が段 2 のアーカイブを占め、段 2 の成功が
落ちた ([2026-10-09_v11_stage2-archive-loop](2026-10-09_v11_stage2-archive-loop.md))。v12 は保存を「段が上がった手の後の形」だけに
してこのループを断つ ([0025](../decisions/0025-archive-save-on-stage-up.md))。0025 の「外れたら仮説が誤りと言える予想」:

1. 段 2 のアーカイブで 1 つの p-data が占める割合が、iteration 300 まで 20% を超えない。
2. 学習ログの段 2 の成功が、途中で半分以下に落ちない。段 0 の時間切れ (`timeout_s0`) が v7 の延長のように増えない。
3. chain 評価が it100 -> it300 で下がらない。

## 結論

- 分かった:
  - v12 は 2 シードとも完走した。段 0 のアーカイブには学習中に何も入らず (128 形のまま)、段 2 の時間切れは全期間 0.6〜1.6% (v11 は it300 で 16〜22%)。0025 が狙った「抜け出せない形が溜まるループ」は起きなかった。
  - chain 評価: s43 は 31〜49% で上下し、it300 (39.8%) は it100 (38.7%) とほぼ同じ。s44 は it70 の 58.8% から it150 の 2.0% に崩れ、it300 で 5.5%。0025 の予想 3 は s43 で当たり、s44 で外れた。
  - 予想 2 の前半: 段 2 の成功の 30 iteration の平均は、s43 が最高 0.134 (it60〜89) から最低 0.074 (it150〜179) で、半分以下には落ちなかった。後半: s44 の `timeout_s0` は it120 以降 0.40〜0.49 に増えた (s43 は 0)。
  - **v12 s44 の段 0 の崩れは、段 0 のアーカイブが学習中に変わらない (台本の 128 形のまま) 中で起きた。** s44 の段 0 の崩れはアーカイブの汚れでは説明できない。
  - **0025 の予想 1 は外れた。** 段 2 のアーカイブで 1 番多い p-data の割合は、両シードとも it100 で既に 20% を超え (s43 30.0%、s44 24.7%)、it300 で s43 40.6%、s44 33.8% に増えた。ただし 1 番多い形は v11 の形 A・形 B (Φ の表に無い罠の形) と違い、どれも Φ の表にある 6 交差の形で、表にある形の割合は 81〜95% (v11 s43 は 37〜42%)。
  - s44 の崩れは段 0 と段 1 で同時に始まった (it70 -> it100 で段 0 の上がる手 74% -> 45%、段 1 は 42% -> 16%)。段 0 の方策は、掴む端と作る輪の型を変えた。
- 推測:
  - v11 s44 と v12 s44 は同じシードで同じ型 (段 0 の時間切れ) に崩れたので、seed 44 の段 0 の方策で起きやすい学習の不安定さがある。
  - 下がりの共通の原因の候補は、方策の平均が行動の範囲の外へ出て張り付くこと ([2026-10-14_action-saturation](2026-10-14_action-saturation.md))。
  - 段 2 のアーカイブの偏りは、段 1 の方策が段 2 に上がるときに作る形の偏り (方策の std が細り、同じ型の手をくり返す) をそのまま写したもので、v11 の「抜け出せない形が溜まるループ」とは別の仕組み。段 2 の時間切れが増えていない (0.6〜1.6%) ことと合う。
- 未確認:
  - v12 と v7 の差 (v7 s44 の延長が無く、比べる相手が 1 シード)。
  - 段 2 のアーカイブの偏りが、段 2 の方策の学習 (始まりの形の多様さ) や chain 評価に効いているか。
