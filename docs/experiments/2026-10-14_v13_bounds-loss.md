# v13 (v12 + PPO の損失に方策の平均の範囲外の罰則) の学習 (seed 43 / 44、iteration 300) と chain 評価 (2026-10-14)

- 状態: 凍結
- 読むべき状況: v13 の結果を v12・v14 と比べるとき。方策の平均が行動の範囲の外へ出る問題 (0026) の次の手を決めるとき

## 目的と仮説

v7・v11・v12 のどれも chain 評価の山が it70〜100 にあり、その後に下がる。全 run で段ごとの方策の平均が行動の範囲 [−1, 1] の外へ
出る割合が増え続け、大きく崩れた run では段 0 の置き方のチャネル (dx・release_z・yaw) まで張り付いた
([2026-10-14_action-saturation](2026-10-14_action-saturation.md))。v13 は PPO の損失に
`bounds_loss_coef · mean_batch(Σ_チャネル max(|μ| − 1, 0)²)` (係数 0.01) を足し、平均を範囲の近くに留める
([0026](../decisions/0026-v13-action-bounds-loss.md))。0026 の「外れたら仮説が誤りと言える予想」:

1. 罰則が効く: 段 0 の置き方のチャネル (dx・release_z・yaw) で |μ| > 1 の割合が iteration 300 まで 20% を超えない。Σ max(|μ| − 1, 0)² の観測の平均が 0.05 を超えない。
2. chain 評価が it70〜100 の後に下がらない: 2 シードとも it300 が、it70・it100 の高い方から 5 ポイント以上は下がらない。
3. s44 が段 0 で崩れない: 学習ログの `timeout_s0` が 0.1 を超えない。

1 が外れたら、罰則が足りないので係数を見直す (この版の結論は保留)。1 が当たって 2・3 が外れたら、張り付きは崩れの原因ではない。

## 結論

- 分かった:
  - **予想 1 は外れた。** 段 0 の置き方のチャネルの |μ| > 1 は、s43 で release_z 30% (it70)・yaw 40% (it300)、s44 で yaw 87% (it150)・release_z 64% (it200)・dy 90% (it300) と 20% を超えた。Σ max(|μ| − 1, 0)² は全 checkpoint で 0.05 を超えた (0.16〜1.61)。0026 の取り決めにより、**v13 では張り付きが崩れの原因かどうかの結論を出さない** (保留)。
  - 罰則は範囲の外への出方の**大きさ**は抑えた: it300 の段 0 の Σ は v12 の 1/3〜1/6 (s44 4.4 vs 14.6、s43 0.8 vs 5.3)、最大の |μ| は 4.4 (v12 s44 は 14.2)。範囲の外にある**割合**はあまり減らなかった (段 0 で v12 の 0.8〜0.9 倍)。
  - 予想 2 は 2 シードとも外れた: s43 は it70 35.5% -> it300 27.7% (−7.8)、s44 は 65.4% -> 5.9% (−59.5)。予想 3 も外れた: s44 の `timeout_s0` は it150 の前後に 0.38〜0.57 になった。
  - v13 s44 は v12 s44 と同じ型に崩れた (段 0 の時間切れが増え、chain 評価の `time_out` が 58〜70%、価値関数の損失が 0.37 -> 3.97)。`timeout_s0` が 0.1 を超えたのは v12 より約 20 iteration 遅かった。
  - it300 の chain 評価は、v13 s43 が v12 s43 を 12.1 ポイント下回り、s44 はどちらも 6% 前後。v13 s44 の it70 (65.4%) はこれまでの版の chain 評価で最も高い。
- 推測:
  - 係数 0.01 の二乗の罰則は、|μ| が 1 を少し超えたところでは弱すぎる (|μ| = 1.5 で 1 チャネル 0.0025)。範囲の外の遠くの裾は削るが、範囲の外に出ること自体は止めない。
  - 崩れの型 (段 0 の時間切れの増加と価値関数の損失の増加) は罰則があっても同じで、時期だけが少し遅れた。張り付きの大きさ (|μ| の大きさ) は崩れの主因ではない見込み。張り付きの割合が原因かは、この結果では分けられない。
  - v13 s43 が v12 s43 を it200 以降に下回ったのは 1 シードの 10〜20 ポイントの差で、罰則の害とは言えない。
- 未確認:
  - 張り付きの計測の観測は v12 の rollout から取った。v13 の方策が実際に訪れる状態での割合は測っていない (`diag_stage_moves.py --dump_obs` を v13 のチェックポイントで回せば測れる)。
  - v13 s44 の崩れが段 0 のどの手から始まったか (`diag_stage_moves.py` の手ごとの診断) は見ていない。
