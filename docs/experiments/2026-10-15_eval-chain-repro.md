# chain 評価の再現性: 決定論的か、512 エピソードは独立か (2026-10-15)

- 状態: 凍結
- 読むべき状況: chain 評価の値の揺れ (同じチェックポイントを測り直すと変わるか、`--seed` が効くか) を知りたいとき、`eval_chain.py` を変えた後の回帰の確かめ方を決めるとき

## 要約

- 結論: chain 評価はこのマシンでは決定論的。測り直し・`--seed`・GPU を変えても全キーがビット単位で同じで、評価を繰り返しても標本は増えない。
- 有効か: 有効 (RTX 3090 × 2)。揺らぎの組を引き直したとき (`--num_envs`・環境の間隔を変える) の揺れは未実測。

> 注記 (2026-10-15、`eval_chain.py` に段ごとの内訳・張り付き・`meta`・`param_check` を足した後): commit `7f4a26d` で同じ条件 (512 環境、seed 7、cuda:1) の 2 本を測り直し、既存のキーが下の表の値とビット単位で一致した (`outputs/eval_repro/after_v13_s44_it70_seed7.json`・`after_v12_s43_it300_seed7.json`、job `outputs/jobs/2026-10-15_20-16-43_eval_regress_v1{3,2}`、`signal:` の行なし)。学習の `params/env.yaml` との照合の違いは 0 件。新しいキーの値はこの 2 つの JSON にある (解釈はしていない)。その後の `2a154cf` の変更は git の状態を読む時点だけで、16 環境のスモークテストで確かめた。

## 目的と仮説

Play (chain 評価) は全環境が同じまっすぐなロープから始まり、段の重みは (1, 0, 0)、方策は決定論的で、`common/mdp/` にアーカイブ以外の乱数は見当たらない (コードを読んだ範囲)。そうなら 512 エピソードは独立な標本ではなく、結末が分かれるのは GPU の物理の細かな違いが接触で増幅されるためだけかもしれない。確かめること:

1. 各環境の最初の手の観測は環境の間で同じか。
2. 同じチェックポイント・同じ条件の評価を繰り返すと値が変わるか (GPU の物理が実行ごとに非決定論的か)。
3. `--seed` を変えると値が変わるか。
4. 過去の記録の値 (別の日時・別の GPU・別の混み方) を再現するか。

## 結論

- 分かった:
  - 各環境の最初の手の観測は環境の間でほぼ同じ (最大の差 2.6e-5 m、リンクの x 座標だけ、4 通り)。行動の差は 4e-5 以下。それでも最初の 1 手の後に結果が分かれ、2 手目の観測は全環境で異なる。
  - chain 評価は、このマシン (RTX 3090 × 2) では**決定論的**。同じチェックポイントを測り直しても、GPU (0 / 1)・GPU の混み方・日時・同時に走るジョブを変えても、全キーがビット単位で同じ。
  - `--seed` (7 / 8) は chain 評価の値を変えない。
  - したがって、評価を繰り返す・`--seed` を変えることでは標本は増えない。評価の揺れ (測り直しの分散) は 0 で、#0 の「ばらつきの範囲」は 0。`eval_chain.py` を直した後の回帰の確かめは、既存のキーが修正の前の JSON と完全に一致することで行える。
  - 記録を取った時点 (`565e90a`・`ecc6254`) から今回までの `common/` の変更 (v14 の DR など) は、v12・v13 の chain 評価の値を変えていない。
- 推測:
  - 最初の観測の 4 通りの差は、環境の原点 (格子の位置) を引くときの float32 の丸め。環境ごとの結末は、環境の位置で決まる丸めの差が接触で増幅されたもので、環境の番号の決定論的な関数になっている。
  - 512 の結末は、同じ 1 つの「揺らぎの組」を固定して測った値。二項の 2 ポイント前後は、その揺らぎの組を引き直したら変わる大きさの見積りとしては使えるが、測り直しでは確かめられない。また、同じ揺らぎの組で 2 つのチェックポイントを比べるので、比較は対になっている (共通の乱数に近い) 可能性があるが、1 手目で結末が分かれるほど増幅が強いので、対の相関は小さいと見る。
- 未確認:
  - `--num_envs` や環境の間隔を変えたとき (環境の原点が変わる) に値がどれだけ動くか。これが「揺らぎの組を引き直した」ときの実測の揺れになる。
  - 512 の結末が互いに独立か (環境の番号や原点の位置と結末に相関があるか)。環境ごとの結末の記録が無いので見ていない。
  - 別の GPU の型・ドライバ・Isaac Sim の版で同じ値になるか (PhysX の `enable_enhanced_determinism` は `false` のまま)。
  - `diag_stage_moves.py` が同じ条件で `eval_chain.py` と同じエピソードの結末を出すか。
