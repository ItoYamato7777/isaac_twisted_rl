# v15 (v14 + 時間切れの bootstrap の修正) の学習と chain 評価 (seed 43 / 44、v14 と比較) (2026-10-16)

- 状態: 凍結
- 読むべき状況: v15 を継承元にするかを決めるとき (v16・v17)。時間切れの bootstrap の不具合の修正が効いたかを知りたいとき

## 要約

- 結論: v15 は 2 シードとも段 0 で崩れず、V も 1/γ = 1.053 を超えなかった (予想 1・2・3・4 は当たった)。chain 評価の `knot` の 2 シード平均は、it200〜300 で v14 を 8〜14 ポイント上回り (it250 で 69.3% 対 55.6%)、it70・100 では 9〜13 ポイント下回り、it150 は同じだった。**差はほぼ s43 の増加で、s44 は v14 と標準誤差の範囲で同じ**。
- 有効か: 2 シードだけ。v14 の切り分け (修正だけの効果) は、v14 と v15 の差が修正だけという構成なので成り立つが、シード間の差が大きい (v15 の it250 で s43 87.5% 対 s44 51.2%)。修正の効果としては「害にならない」までは言え、「頭打ちを上げる」は s43 の 1 本のみで、推測。動画は撮ったが中身は見ていない (判断はユーザー)。

## 目的と仮説

[0028](../decisions/0028-v15-timeout-bootstrap-fix.md): 時間切れの bootstrap の不具合 (最後の手で段が変わる手に γ·V を足す) を直すと、(1) 段 0 の V が膨らまない、(2) 6 手目に段 0 を上げる山が出ない、(3) 段 0 が崩れない、(4) chain 評価が段 0 から崩れない。継承元は v14。v14 は崩れなかったので 3・4 は当たっても仮説を支持せず、見るべきは「修正が害にならないか」と、v14 でも不具合が性能を削っていたか。

## 結論

- 分かった:
  - v15 は 2 シードで段 0 が崩れず、段 0 の V は 1/γ を超えない。時間切れの項を差し替えた副作用 (崩れ・段の下降・発散の増加) は出ていない。
  - 2 シード平均の `knot` は、it150 以降の 3 点で v14 以上 (−2.1, +12.3, +13.8, +8.1)。it70・100 では v14 より 9〜13 ポイント低く、**両シードとも**低い (s43 −13/−8、s44 −13/−10)。
  - v15 の発散率は it200 以降 v14 より低い (平均 10.3% 対 17.1% など)。
  - 増加は s43 に集中する (it250 で +26.6)。s44 の it200 以降は v14 と区別できない (差 −2〜+2)。
- 推測:
  - 初期 (it70・100) の落ち込みと `time_out` の増加 (38.7% から 49.6%) は、修正で「最後の手まで待って上げる」得が消え、学習の初期に段を上げるまでに要る手数が増えたため。確かめていない (v15 の早い iteration の手の列を数えていない)。
  - s43 の it200 以降の増加は、修正で critic の V の歪み (v14 s43 は固定した観測で V が 1/γ を 43% の行で超えていた) が無くなり、段 1・2 の手数が減ったため。段 1 の手数の減り (5.3 から 2.6) と整合する。ただし 1 シードで、s44 は同じ手数 (5.0 から 4.7) で増えていない。
  - s44 は v14 と同じく段 2 から固結びへの率が 0.56 で頭打ちで、段 2 の詰まりは修正で解けていない ([段 2 の詰まりの記録](2026-10-15_timeout-bootstrap-and-stage2-bottleneck.md)と整合)。
  - v14 が崩れなかったのは段 0 の保存の規則が不具合の突き所を潰したため (v14 の記録の推測)。v15 の結果はこれと矛盾しない (v14 でも V の歪みは小さく、修正の効果は崩れの防止ではなく s43 の上積みとして出た)。
- 未確認:
  - 修正が効いたのか、シードの違いか。シード間の差が大きい (v15 の it250 で 36 ポイント、v14 は 10 ポイント以内)。3 本目のシードを回せば分かる。
  - DR 付きの評価は回していない。
  - 動画の内容 (ユーザーが判断する)。
