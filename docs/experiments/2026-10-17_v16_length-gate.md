# v16 の長さの組 (角度制限 ±60° に揃えた ×0.8 / 1.0 / 1.25 と ×1.1) のゲート 1・発散・スモークテスト (2026-10-17)

- 状態: 凍結
- 読むべき状況: v16 の長さの組 (×0.8 / 1.0 / 1.1) を決めた根拠を知りたいとき。角度制限を揃えたときの長い組の発散を知りたいとき

## 要約

- 結論: 関節の角度制限を 3 組とも公称 (曲げ ±60°・捩り ±90°) に揃えると、長さ ×1.25 の台本は 25/128 しか結べず、1 手あたりの発散は 14.7% (物理の DR なし) だった。×1.1 に替えると 100/128・8.8% になった。×0.8 と ×1.0 はどちらの run でも台本 119〜126/128、発散 1.3〜3.6% で、寸法を混ぜても公称の組の発散は 3.0〜3.2% (公称だけの 2.83% に近い。直径も振った 9 組の run では 7.3%)。スモークテスト (×1.1 の組) は 2 iteration 走り、critic の入力は 205 次元、PhysX のエラーは 0。これで v16 の学習 (seed 43 / 44) を始めた。
- 有効か: 台本 (開ループ、1 組 128 env) と一様乱数の手 (1 組 24576 手) での計測。学習した方策では違いうる。×1.1 の組の発散は公称の約 2.7 倍のまま残る。ゲートの閾値は先に決めていない (0029 の判断 1)。

## 目的と仮説

[ゲートの記録](2026-10-17_v16_size-gate.md) の後、ユーザーが組を長さだけ (直径 ×1.0) にし、関節の角度制限を 3 組で揃えることにした ([0029](../decisions/0029-v16-rope-size-dr.md) の「ゲートの後に決めたこと」)。

- 1 回目 (×0.8 / 1.0 / 1.25): 角度制限を揃えたとき、各組が台本で結べるか、寸法を混ぜたときの公称の組の発散が 9 組の run の 7.3% から下がるか (下がれば、増加の原因はアーカイブの関節角が書き戻し先の制限を超えることという推測と合う)。
- 2 回目 (×0.8 / 1.0 / 1.1): 1 回目で ×1.25 が悪かったので、ユーザーが ×1.1 に替えた。×1.1 がゲートを通るか、学習の起動 (スモークテスト) が通るか。

## 結果

### ゲート 1 (固結び / 128、括弧は発散)

| 組 (長さ) | 物理の DR なし | 物理の DR あり |
|---|---|---|
| ×0.8 (1 回目 / 2 回目) | 122 (0) / 119 (0) | 76 (8) / 72 (7) |
| ×1.0 `knot` (1 回目 / 2 回目) | 125 (1) / 126 (2) | 92 (11) / 90 (4) |
| ×1.25 (1 回目) | **25** (36) | 32 (51) |
| ×1.1 (2 回目) | **100** (11) | 63 (27) |
| 参考: 前の記録 (導出した角度制限、9 組の run) ×0.8 / ×1.0 / ×1.25 | 111 / 127 / 78 | 77 / 97 / 64 |

×0.8 と ×1.0 の 2 回の差 (最大 4/128) は、同じ物理・同じ組で、混ぜる相手の組だけが違う。

## 結論

- 分かった:
  - 角度制限を 3 組で揃えて直径を ×1.0 に限ると、寸法を混ぜても公称の組の発散は 3.0〜3.2% (DR なし) で、公称だけの 2.83% に近い。9 組の run の 7.3% から下がった。
  - 角度制限を ±60° に揃えた長さ ×1.25 は、台本 25/128・発散 14.7% (DR なし) で、導出した制限 (±77.4°) のとき (78/128・9.9%。直径も振った 9 組の run の値) より悪い。
  - ×1.1 は台本 100/128 (DR あり 63/128)・発散 8.8% / 8.2% (DR なし / あり)。×0.8 (1.3%)・×1.0 (3.2%) より発散が多く、1 手目より 9 手目以降で多い (5.2% -> 9.3%)。
  - ×1.1 の組でスモークテストが通った (2 iteration、critic 205 次元、PhysX のエラー 0)。
- 推測:
  - 公称の組の発散が 9 組の run より下がったのは、アーカイブの関節角が書き戻し先の制限を超えなくなったため (前の記録の推測と合う。今回は角度制限と直径の組の 2 つを同時に変えたので、どちらが効いたかは分けていない)。
  - 長い組の発散が多いのは、角度制限が同じでリンク間隔だけが長いため (リンクが細長く、最小曲げ半径が直径の 2.2〜2.5 倍に広がる) と考えるが、確かめていない。
- 未確認:
  - 学習した方策で ×1.1 の組の発散がどれだけ出るか、学習を崩すか。
  - 学習の 1 iteration の時間が v15 と比べてどれだけ遅いか (spawn の記録ではランダムな手で 77%)。
