# v16 の寸法の組ごとの物理のゲート (ゲート 1・発散・把持) (2026-10-17)

- 状態: 凍結
- 読むべき状況: v16 の寸法の DR の組を決めるとき。細い紐 (直径 ×0.4 = 実機の 8 mm) を今の紐モデルで扱えるかを知りたいとき

## 要約

- 結論: 今の紐モデル (28 リンク) では、直径 ×1.0 の 3 組だけが台本で固結びを結べる (128 中 78〜127)。直径 ×0.4 (実機の太さ) の 3 組は 0〜2/128 で、主な原因は把持の失敗 (carry の終わりに持ち上がっている手が 6〜7%)。指のゲインを紐から導いた値 (513 N/m) に下げると把持は増えるが発散が 3 倍に増え、やはり結べない (2/128)。直径 ×0.63 の 3 組も 2〜21/128。また、寸法の違う env を同じ学習に混ぜると、公称の組の発散も 2.8% から 7.3% に増える (アーカイブの書き戻しが原因と推測)。
- 有効か: 台本 (開ループ) と一様乱数の手での計測。学習した方策では違いうる (v14 のゲートの教訓)。混ぜたときの発散の原因 (アーカイブ) は推測。

## 目的と仮説

[0029](../decisions/0029-v16-rope-size-dr.md) の判断 1: 寸法の 9 組それぞれでゲート 1 と 1 手あたりの発散率を測り、通らない組を外す。閾値は先に決めない。実機に近い組が残らなければユーザーと相談する。

## 結論

- 分かった:
  - 今の紐モデル (同じ材料・28 リンク・リンク間隔を長さで伸縮) で台本が固結びを結べるのは直径 ×1.0 の 3 組 (×0.8: 111、×1.0: 127、×1.25: 78 /128、物理の DR なし)。直径 ×0.4 と ×0.63 の 6 組は 0〜21/128。
  - 直径 ×0.4 の組は、指のゲインが公称のままでは掴んで持ち上げられない (把持 6〜7%)。ゲインを 513 N/m に下げると掴めるようになるが、1 手目で半分が発散する。
  - 直径 ×0.63 の組は掴めるが (把持 83〜85%、×0.8 だけ 26%)、発散が公称の 2〜3 倍 (13〜21%)。
  - v16 のコードは公称の寸法だけなら v14 / v15 と同じ発散・把持になる (2.83%・99.1%)。
  - 寸法の違う env を混ぜると、公称の組の発散が 7.3% (混ぜないと 2.8%) になる。リセットの直後の 1 手目は 0.8% で、9 手目以降に 7.7% に上がる。どの組も 1 手目より後の手の発散が多い。
- 推測:
  - 混ぜたときの発散の増加は、アーカイブを寸法の間で共有しているため。細い組 (曲げの角度制限なし・×0.63 は 79〜166°) や長い組で保存した形の関節角が、書き戻し先の組の角度制限 (公称 ±60°、×0.8・×1.0 は ±47°) を超え、リセットの直後に関節の制限が一気に効いて飛ぶ。公称の組の発散の 56% (448 中 251) が手の最初のフェーズ (approach・descend) で始まることと合う。学習の初期アーカイブ (公称の寸法で作った形) も、×0.8・×1.0 の組の角度制限 (±47°) を超えうる。
  - 直径 ×0.4 の把持の失敗は、リンクの質量 (1.1〜1.7 g) に対して指の押し付けが強すぎるため (質量あたりの押し付けが公称の約 3 倍。`RopeSpec.grasp_finger_stiffness` の docstring の `fine` と同じ型)。細い組はリンク間隔が直径の 4〜6 倍あり、リンクが細長い棒になることも、発散の多さに効いていると考える。
- 未確認:
  - 直径 ×1.0 の 3 組だけを混ぜたときの発散 (今回の値は細い組と混ぜたもの)。
  - 学習した方策で細い組を扱えるか (台本は開ループ)。
