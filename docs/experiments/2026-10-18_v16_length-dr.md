## 要約

- 結論: v16 は 2 シードとも段 0 で崩れず、段 0 の V も 1/γ を超えなかった。公称の寸法の chain 評価の `knot` の 2 シード平均は、最後の点 (v16 it299 対 v15 it300) で 64.7% 対 65.7% と同じだった。一方 it150〜250 では v15 を 10〜19 ポイント下回り、発散も多い。寸法を振った評価 (×0.8 / 1.0 / 1.1 を 1/3 ずつ) と公称の評価の差は、2 シード平均で −6〜+5 ポイントで、向きは一定しない (it299 で 59.2% 対 64.7%)。
- 有効か: 2 シードだけ。v15 を寸法を振ったロープで評価した結果は [後の記録](2026-10-19_v15-sized-eval_length-dr-effect.md) (寸法を振ったロープでの `knot` は v15 と同じ。公称からの落ちは v15 s43 だけが大きく、v16 は落ちない)。寸法を振った評価は組ごとの内訳が無い (eval_chain が env ごとの寸法を記録しない)。最後の点は v16 が it299、v15 が it300 (学習の `--max_iterations` が 300 と 301 で違う)。動画は撮ったが中身は見ていない (判断はユーザー)。

## 目的と仮説

[0029](../decisions/0029-v16-rope-size-dr.md): ロープの長さを env ごとに振って学習し (×0.8 / 1.0 / 1.1、直径 ×1.0、角度制限は公称に揃える。組を決めた経緯は [長さのゲート](2026-10-17_v16_length-gate.md))、方策が寸法の違いを吸収できるかを見る。比べる相手は v15 の同じ seed。

仮説 (STATUS に書いたもの): 長さの DR を入れても公称の寸法の `knot` は v15 から大きく落ちない。寸法を振った評価では ×1.1 の組の発散が足を引っ張る。

## 結論

- 分かった:
  - v16 は 2 シードで段 0 が崩れず、段 0 の V は 1/γ を超えない (学習ログ)。chain 評価で `stage_down` は 0。
  - 公称の寸法の `knot` は、最後の点で v15 と同じ (2 シード平均 64.7% 対 65.7%、シードごとの差 −2.4・+0.4 は標準誤差の範囲)。
  - it150〜250 では 2 シード平均で v15 を 10〜19 ポイント下回り、両シードとも下回る (s43 −12〜−36、s44 −1〜−16)。この区間は `diverged` が v15 より 5〜10 ポイント多く、`max_stage_ge3` が 10〜19 ポイント少ない。
  - it70・100 は s43 が v15 より 22〜26 ポイント高く、s44 が 11〜20 ポイント低い。2 シード平均の差は +8・+1。
  - 寸法を振った評価と公称の評価の差は、2 シード平均で −6〜+5 ポイント、6 点の平均でほぼ 0 (47.1% 対 47.3%)。ただしチェックポイントごとには差の標準誤差 (約 3) を超えて動く (s43 で −18〜+17)。寸法を振った評価の `diverged` は公称と比べて −1〜+4 ポイント (it70・100・299 で +2〜+4。it299 で 15.1% 対 11.6%)。
  - 1 iteration の時間は v15 と同程度 (224・220 s 対 223・271 s)。spawn の記録のランダムな手の計測 (v15 の 77% の速さ) ほどは遅くなっていない。
- 推測:
  - it150〜250 の低さは、長さの DR で課題が難しくなり、学習が遅れたため。最後の点で追いつくので、上限が下がったのではなく遅れと見るが、it300 より先を回していないので確かめていない。比べる相手の v15 s43 が特に高い run (it250 で 87.5%) なことも差を大きくしている。
  - 寸法を振った評価の発散の多さは、×1.1 の組の発散 (ゲートで公称の約 2.7 倍) による。組ごとの内訳が無いので確かめていない。
  - 学習の時間が v15 と同程度なのは、GPU の共有の具合が違ったため (v15 s44 の 271 s は他のジョブと重なった可能性)。記録が無く、確かめられない。
- 未確認:
  - **長さの DR が寸法の違いへの頑健さを上げたか**。v15 の方策を寸法を振ったロープで評価していない (v15 の checkpoint を v16 の Play で読めるか (critic 203 次元 対 205 次元) も未確認)。
  - 寸法の組ごとの `knot` と `diverged` (eval_chain に env ごとの寸法の記録が無い)。
  - 3 本目のシード。it299 と it300 の 1 iteration の違いの影響 (小さいと見ているが測っていない)。
  - 動画の内容 (ユーザーが判断する)。
