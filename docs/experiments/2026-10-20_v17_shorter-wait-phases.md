# v17 (v15 + 待ちのフェーズの尺を詰める) の学習 (seed 43 / 44) と chain 評価、v15 との比較 (2026-10-20)

- 状態: 凍結
- 読むべき状況: v17 の採否を決めるとき。待ちのフェーズの尺を詰めることが学習に効くかを知りたいとき。学習の速さのために 1 手の尺や物理を変えたくなったとき

> 2026-10-20 注記: この結果を受けて、ユーザーが v17 を不採用に決めた ([0030](../decisions/0030-v17-shorter-wait-phases.md) の「結果と不採用」)。

## 要約

- 結論: v17 は 2 シードとも v15 を下回った。it150〜300 の 4 点の `knot` の平均は、s43 で 73.0% → 41.1% (−31.9 ポイント)、s44 で 49.7% → 42.6% (−7.1 ポイント) で、[0030](../decisions/0030-v17-shorter-wait-phases.md) の予想 1 (2 シードとも 5 ポイントを超えて下がらない) は外れた。速さは bench で v15 の 0.766 倍で、予想 2 は当たった ([ゲート](2026-10-19_v17_gate.md))。chain 評価の発散は、it150 以降のすべての点で v17 が v15 より高い。
- 有効か: 2 シード・iteration 300 まで。v15 は 2 シードの差が大きく (it150〜300 の平均 73.0% と 49.7%)、s43 の差 −31.9 には v15 s43 が高いシードであることも含まれる。v17 の 2 シードはそろって 41〜43% だった。尺のどのフェーズが効いたかは切り分けていない。

## 目的と仮説

0030: 待ちのフェーズ (close・hold・release・settle_out・relax) を詰めれば、1 手の物理ステップ数が 759 → 591 になり、学習が約 1.28 倍速くなる。v14 の方策をこの尺で chain 評価したときは固結びが −0.3 ポイントだったので、0 から学んでも質は保たれる、という仮説。予想 1〜4 は 0030 にある。

## 結論

- 分かった: 待ちのフェーズを詰めた尺で 0 から学ぶと、2 シードとも it150〜300 の `knot` が v15 を下回った (−31.9・−7.1 ポイント)。0030 の予想 1 と 3 は外れ、速さの予想 2 は当たった。0030 の読み方では「尺を詰めて速くなった分、学習の信号が悪くなった」に当たる。
- 分かった: v17 の chain 評価の発散は、it150 以降の 8 点すべてで v15 の同じシードより高い (s43 17.6〜24.2% 対 3.9〜11.9%、s44 14.5〜16.8% 対 9.4〜13.9%)。時間切れも 8 点中 7 点で多い (s44 の it250 だけ v15 が多い)。段 0 から崩れた run は無く、落ちたのは段 1 で時間切れ・発散する分と、段 2 から固結びに届く割合 (`p_knot_given_ge2`)。
- 分かった: 学習ログの上の発散 (v15 との差 0.2〜0.3 ポイント) と、段の判定のずれ (`restore_mismatch` など) は v15 と同じだった。学習ログの指標では差が見えず、chain 評価でだけ差が出た。
- 推測: 学習済みの v14 の方策を D4 の尺で評価したときは発散が増えなかった (0030) のに、D4 の尺で学んだ方策は chain 評価で発散が多い。方策が、落ち着いていないロープ (1 手の終わりに動いているロープは bench で v15 の約 3 倍) の観測から学ぶことが効いているのかもしれない。どのフェーズ (settle_out・relax など) が効いたかは切り分けていない。
- 推測: v17 s43 の it100 の 74.6% は前後の点 (34.6・35.5) から大きく外れていて、隣のチェックポイントの揺れ (平均 9 ポイント) より大きい。1 点だけの高さで、学習が安定していないことの表れかもしれない。
- 未確認: v15 も 2 シードの差が大きい (it150〜300 の平均 73.0% と 49.7%) ので、s43 の差の大きさは v15 s43 が高いシードであることにもよる。シードを増やせば差の大きさは変わりうる (向きは 2 シードで同じ)。
