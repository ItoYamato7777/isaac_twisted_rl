# v15・v16 の物理 DR 付き chain 評価 (seed 43 / 44、it200 / it300) (2026-10-22)

- 状態: 凍結
- 読むべき状況: 物理の違い (剛性・質量・減衰・摩擦) に対する方策の頑健性を版どうしで比べるとき。v15 と v16 のどちらを次の版の継承元にするかを決めるとき。Sim2Real のギャップへの強さを、公称の評価以外の指標で見たいとき

## 要約

- 結論: 物理 DR (6 軸) を付けた chain 評価の `knot` は、最後の点 (v15 it300・v16 it299) の 2 シード平均で v15 が 54.5%、v16 が 53.6%。公称の評価からの下がり幅は、どちらも約 −11 ポイント (v15 −11.2、v16 −11.1)。v14 の DR 付き it300 (50.7%、公称から −6.9) と比べても、3 版は 2 シードでは区別できない。it200 の下がり幅は v15 が −10.0、v16 が +1.7 で、v16 のほうが小さいが、最後の点では同じになる。
- 有効か: 2 シード・各版 2 点 (it200・最後) だけ。シード差が大きい (v15 の公称は s43 76.6% 対 s44 54.9% だが、DR 付きは 56.4% 対 52.5% でほぼ同じ)。env ごとの倍率は JSON に残らないので、どの軸で落ちたかは分からない。DR の倍率の並びが v14・v15・v16 で同じかは未確認 (v16 は `replicate_physics` が偽)。

## 目的と仮説

v14 の DR 付き評価 (it100・it300) は、公称からの下がり幅が平均 −8 ポイントで「DR で頑健になったとは言えない」だった ([v14 の記録](2026-10-15_v14_s0-reshape-dr-priv-critic.md))。v15 以降の物理 DR 付きの評価が無かったので、公称の `knot` が最も高い v15 と、長さの DR を足した v16 で測る (ユーザーの指示、2026-10-22。対象は v15・v16、it200・it300、条件は物理 DR だけ)。

事前に置いた仮説はない (測って分布を知る評価)。見るもの: DR 付きの `knot` の値、公称からの下がり幅、v14 との差。

## 結論

- 分かった:
  - v15・v16 とも、物理 DR を付けると `knot` は 2 シード平均で最後の点が約 11 ポイント、it200 が v15 で 10 ポイント下がる (v16 の it200 は +1.7)。発散は 4〜7 ポイント増える。
  - 最後の点の DR 付きの `knot` は v14 50.7%、v15 54.5%、v16 53.6%。差は 4 ポイント以内で、シード差 (v15 の公称で 22 ポイント) より小さく、2 シードでは版どうしを区別できない。
  - v15 の公称の s43 と s44 の差 (76.6 対 54.9、it300) は、DR 付きではほぼ消える (56.4 対 52.5)。v15 の下がり幅は s43 に集中している (−15.7・−20.2。s44 は −4.3・−2.4)。
  - v16 は it200 で公称より下がらなかったが (+0.2・+3.1)、これは公称の値が低い点 (56.8・32.8) と重なる。最後の点では s43 −13.3、s44 −9.0 で、v15 と同じ水準に下がる。
  - 公称で最高の点 (v15 s43 it250 の 87.5%) の DR 付きの評価は無い (今回は it200・300 だけ)。
- 推測:
  - v15 の公称の成績の高さのうち s43 の突出分は、公称の物理に合っていたことによるもので、物理の違いには持ち越されない (DR 付きで s43 と s44 がほぼ同じになったことから。1 点どうしの比較なので推測)。
  - 長さの DR (v16) は、物理 DR への強さを上げていない。it200 だけ下がり幅が小さいが、最後の点で同じになるので、公称の値の高さの違いで説明できる。
  - 物理 DR で学習した 3 版 (v14・v15・v16) が、DR 付きの評価で約 50〜55% に並ぶのは、学習の DR の範囲 (×0.5〜×2) の端の物理で失敗するためかもしれない。軸ごとの内訳が無く、確かめていない。
- 未確認:
  - どの軸 (剛性・質量・減衰・摩擦) で失敗するか。`eval_chain.py` が env ごとの倍率を JSON に残さない (STATUS の「次の作業」3)。
  - 倍率の並びが v14・v15・v16 で同じか。v14 の記録は「env ごとの倍率は seed で決まる」とするが、v16 は `replicate_physics` が偽 (長さの割り当てのため)。同じなら env 単位の対の比較ができる。
  - it70・100・150・250 の DR 付きの値、公称で最高の点 (v15 s43 it250) の DR 付きの値。
  - 物理 DR と長さの DR の両方を振った評価 (v16)。

## 次の作業

1. 失敗する軸を知りたければ、`eval_chain.py` に env ごとの倍率の記録を足す (既定の評価とビット単位で一致することを確かめてから)。足してから DR 付きの評価を測り直すと、軸ごとの落ち方が見える。
2. 継承元を v15 にするかの判断材料としては、DR 付きでも v15 は v14 以上で、v16 とは同じ。長さの DR を入れる根拠は、この評価からは出ない。
3. DR 付きの `knot` を上げるなら、DR の範囲を変える・広げる版が候補 (範囲の端で落ちる推測を確かめてから)。ユーザーと決める。
