022 つの状態空間 Q と S

ロープの状態は 2 つの粒度で扱います。

  • 低レベルの状態 q ∈ Q: ロープの形そのもの。TWISTED ではロープを L 個のリンクの鎖として表し、Q ⊆ ℝ2L+5 です。先頭の 7 次元は真ん中のリンクの位置 (x, y, z) と姿勢 (クォータニオン) で、残りの L−1 個の関節はそれぞれ yaw と pitch の 2 値で表します TWISTED §2 脚注1。
  • 高レベルの状態 s ∈ S: 交差の並び方だけを残した離散の「位相状態」。形が違っても、交差の上下関係と順番が同じなら同じ s です。

Q から S への写像を Top: Q → S と書きます TWISTED §2。計画は S の上で行い、実行は Q の上で行います。

この分け方には利点があります。S では状態の数が有限で、次にとれる手 (位相遷移) も数えられるので、グラフ探索ができます。一方で「同じ s に属する無数の q のうち、どれにいるか」で次の遷移の成功しやすさが変わります。Yan2020 の多段微調整と TWISTED-RL の多段エピソードは、どちらもこの点に手を打っています。

03p-data: 位相状態の書き方

3 本とも、位相状態の表現に p-data を使います。p-data は Morita ら (2003) と Takamatsu ら (2006) の表現で、作り方は次の 4 段階です Yan2020 §IVTWISTED 付録 7.1。

  1. 3 次元のロープを水平面 (机の面) に射影する。
  2. 片方の端を頭 (head)、もう片方を尾 (tail) と決める。
  3. 頭から尾へたどり、交差に出会うたびに 1, 2, 3, … と番号を振る。1 つの交差は 2 回通るので、番号を 2 つもらう。
  4. もう一度たどり直し、各番号について「交差の相手側の番号」「自分が上 (o) か下 (u) か」「交差の符号 (+/−)」を記録する。

交差が n 個なら p-data は 4 行 × 2n 列の表になります。1 行目は常に 1, 2, …, 2n なので、実質的な情報は下の 3 行です。

読み方の例: 固結びの p-data は 1 2 3 4 5 6 / 4 5 6 1 2 3 / u o u o u o / + + + + + + です (§06 の図)。1 列目は「頭からたどって最初の交差は、6 番目の通過のうち 4 番目と同じ場所で、ここでは自分が下を通り、符号は +」と読みます。u と o が交互に並ぶのは、固結びが「交代結び目」だからです。

交差が増えると、ありうる p-data の数は急に増えます。TWISTED-RL の付録によると、交差 0 の状態は 1 つ、交差 1 は 4 つ、交差 2 は数十、交差 3 で数百になります TWISTED-RL 付録 VIII-A.6。TWISTED は交差 3 で 500 超、交差 4 でほぼ 8000 と見積もっています TWISTED §5.4。

04交差の符号

符号は、上の紐と下の紐の進む向き (頭→尾) で決まります Yan2020 式(1)。

sign = ( l_over × l_under ) / | l_over × l_under | · e_z

lover と lunder は、交差点での上の紐と下の紐の向きのベクトル、ez は射影面 (机) の上向きの法線です。机を真上から見て x を右、y を上にとると、「下の紐が右へ進むとき、上の紐が手前 (下向き) へ進むなら +」になります。

R2 で作る 2 つの交差は必ず符号が逆になります (後述)。符号は「どちら向きにねじれているか」を表すので、固結びの右手系と左手系 (鏡像) を区別できます。Yan2020 は、固結びには鏡像の関係にある 2 つの位相がある、と書いています Yan2020 §IV。

053 種類の位相遷移: R1 · R2 · Cross

位相状態のあいだを移る操作には、結び目理論の Reidemeister 移動を使います。3 本とも、交差を増やす次の 3 種類だけを使い、R3 (交差数を変えずに並びを入れ替える移動) は扱いません Yan2020 §IVTWISTED-RL 付録 VIII-A.5。

各移動には、どの区間を使うかなどの離散パラメータが付きます。Yan2020 はこれを次のように定義しました。区間 (segment) は、交差点で区切った射影曲線の断片で、頭から 0, 1, 2, … と番号を振ります Yan2020 Table I。

パラメータ使う移動意味
indexR1新しい交差 (ループ) を作る区間の番号
over_indexR2, C新しい交差で上になる区間の番号
under_indexR2, C新しい交差で下になる区間の番号
leftR1, R22 値。新しくできる面 (囲まれた領域) が、上の区間の左側にあるか
signR1, C2 値。新しい交差の符号
over_firstR2 (over_index = under_index のとき)2 値。区間のうち頭に近い半分が、新しい交差で上になるか

たとえば R1(0, 1, 1) は「区間 0 でループを作り、新しい面は左側、符号は +」、C(2, 0, 1) は「区間 2 を区間 0 の上に交差させ、符号は +」という意味です。

06固結びを遷移の列として見る

固結び (overhand knot) は交差 3 の結び目です。素のロープから R1 を 1 回、Cross を 2 回行うと作れます。下の図は、その途中の 4 つの状態と p-data です。

図の数字 a·b は、その交差が頭からたどって a 番目と b 番目に通る場所であることを示します。点線の丸は各段階で新しくできた交差です。最後の p-data は Yan2020 の Fig. 2 に載っている固結びの表と一致します。

固結びへの経路は 1 通りではありません。Yan2020 は、固結び (鏡像の 2 つ) への位相の経路が 8 通りあると述べ、そのうち 2 つを図示しています Yan2020 §IV, Fig. 1。実験で使った経路は R1(0,1,1) → C(0,1,1) → C(2,0,1) です。上の図は、尾の側を動かす経路で描いています。

TWISTED-RL の Fig. 1 には、実際に結んだ 2 つの例があります。8 の字結び (Figure-8) は ϕ = 0 → 1 (R1) → 2 (Cross) → 3 (Cross)、固結びは ϕ = 0 → 1 (R1) → 2 → 3 → 4 (Cross 3 回) と表示されています TWISTED-RL Fig. 1。

解釈数学的には 8 の字結びの交差数は 4、固結びは 3 です。上の Fig. 1 の数字はこれと逆に見えますが、原文のキャプションは「左が 8 の字、右が固結び」です。図の配置が入れ替わっている可能性があります。本文中の数字は Fig. 1 の表示をそのまま書き写しました。

07行動: 掴んで、運んで、置く

3 本とも、ロボットの 1 手を「ロープのどこかを掴み、持ち上げ、運び、机に置く」という長い軌道 1 本で表します。1 ステップごとの微小な移動を行動にすると、1 回の交差を作るのに何百ステップも要ります。長い軌道を 1 手にすると、1 回の位相遷移がおおむね 1〜数手で済みます Yan2020 §V。

TWISTED は Yan2020 の観察を引用し、「この曲線の空間で、ある位相状態から可能な Reidemeister 移動のほとんどを近似できる」としています TWISTED §2。一方で、位相遷移に必要な精度は高く、曲線のパラメータを細かく離散化しただけでも結果の位相が変わります (TWISTED §5.1)。

08なぜ難しいのか

状態空間が大きく、連続

ロープは自由度が非常に大きく、同じ位相状態に属する形が無数にあります。形によって次の遷移の成功しやすさが変わります。

目標が「形」ではなく「位相」

「交差の並びがこうなっていればよい」という目標は、形の距離のような連続なコストに書けません。Yan2020 はこれを「抽象的な位相目標に対する直感的なコスト関数が無い」と表現しています。

ランダムでは奥へ進めない

TWISTED の測定では、ランダムウォークで交差 3 の状態に届いたのは CPU コア 1 つあたり 1 時間に 27 状態だけでした TWISTED §4.5。ランダムに動かすとロープはむしろほどける方向に動きます。

報酬が疎

成功した位相遷移はまれで、ほとんどの試行は失敗します。TWISTED の SAC+HER は交差 1 の問題は解けても、交差 2 ではほぼ 0% でした TWISTED §5.2。

3 本は、この難しさに対して次の順に手を打っています。Yan2020 は人間のデモで探索を絞り、TWISTED は到達した状態から探索とデータ収集を始め直し、TWISTED-RL は遷移ごとに専用の方策を学習して、到達済みの状態からエピソードを始めます。

10用語集

位相状態 (topological state)
ロープを机に射影したときの、交差の並び・上下・符号だけで決まる離散の状態。p-data で表す。
p-data
位相状態の表現。頭から尾へたどった交差の番号、相手の番号、上下、符号を 4 行の表にしたもの。
交差数 (crossing number)
TWISTED では位相状態に含まれる交差の数 Cross(s)。TWISTED-RL では ϕ(S) と書き、難しさの目安に使う。
Reidemeister 移動
結び目の位相を変える基本操作。3 本とも R1 (ループ)、R2 (2 交差を同時に作る)、Cross (端で交差を作る) を使い、R3 は使わない。
頭 (head) / 尾 (tail)
ロープの両端。p-data を作るときのたどる向きを決める。
区間 (segment)
射影した曲線を交差点で区切った断片。頭から 0, 1, 2, … と番号を振る。
Top(q)
ロープの形 q を位相状態 s に写す関数。
曲線 c / スプライン
ロボットの 1 手。掴む点・高さ・置き先で決まる長い軌道。
Mirror / Reverse
形を鏡に映す変換と、頭と尾を入れ替える変換。学習すべき位相動作の種類やデータを 4 倍に広げるのに使う。
固結び (overhand knot)
交差 3 の最も単純な結び目。3 本とも主要な例題にしている。
