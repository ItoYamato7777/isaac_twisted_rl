# v8: v7 + PPO の更新に対称性のデータ拡張 (鏡像・逆順)

```bash
uv run train --task Isaac-Twisted-RL-Knot-v8 --headless           # 段ごとの MLP + データ拡張
uv run play  --task Isaac-Twisted-RL-Knot-Play-v8 --num_envs 16   # まっすぐなロープから段をつないで評価 (chain モード)
```

ログ: `logs/rsl_rl/knot_tying_v8/`。**学習には `Knot` プリセットを使う** (v3〜v7 と同じ)。

## なぜ作ったか

v7 は chain 評価で v6・v4 を上回ったが ([`docs/experiments/2026-10-04_v7_seeds.md`](../../../../../../docs/experiments/2026-10-04_v7_seeds.md))、
学習ログでは段 2 -> 固結び (tuck) の成功が 0.19〜0.24 に留まり、ここが一番の詰まりになっている (段 0 は 0.97)。
成功が稀な遷移ほど、1 回の成功から多くを学べるほうがよい。

固結びの課題は 2 つの対称性を持つ (Yan2020 / TWISTED の Mirror / Reverse。`paper/Report_Paper.md` §7 P2-1)。

* **鏡像** (y -> −y): 鏡に映した形状で、鏡に映した手を打てば、鏡に映した結果になる。固結びの判定は左右の三葉結びを区別しない。
* **逆順** (リンクの番号を逆にたどる): 同じ形状を反対の端から数えただけ。同じ手を、番号を付け替えて表せる。

PPO の更新で、集めた遷移をこの 2 つで変換して 4 倍のデータにする。物理は 1 手も増えない。
P2 の他の 3 案 (RND・初期形状のランダム化・推論時探索) を入れない理由は
[`docs/decisions/0022-p2-one-version-each.md`](../../../../../../docs/decisions/0022-p2-one-version-each.md)。

## v7 から何を・なぜ変えたか

| 項目 | v7 | v8 | 理由 |
|---|---|---|---|
| PPO の `algorithm.symmetry_cfg` | なし | `use_data_augmentation=True`、`use_mirror_loss=False`、`augment_mirror_reverse` (4 倍) | 上の「なぜ作ったか」 |
| 環境 (観測・報酬・終了・アーカイブ・行動・物理・Play) | | v7 のまま | 1 版 1 変数 |

観測は v7 と同じ (197 次元) なので、v7 のチェックポイントから `--resume` で暖機開始できる。

### 変換の中身

詳しくは `common/topology/symmetry.py` の docstring。要点:

| | 観測 | 行動 |
|---|---|---|
| 鏡像 | リンク位置・手の位置の y を反転。交差の符号・writhe が反転 | 置き先 y と置き終わりの yaw の符号を反転 |
| 逆順 | リンク位置の並びを逆に。点番号が逆順 | 掴むリンク N−1−l、Δlink を −Δ、置き終わりの yaw を **+π** |

* 交差数・writhe・交差の特徴・class は、変換したリンク位置から環境と同じ関数で**計算し直す**。
* 次にたどる辺 (`next_edge`) は環境が状態を持って選ぶので、選んだ辺の特徴を解析的に変換する。対応は表の全 552 本の辺で確かめた。
* 段の one-hot は変えない。段・class が鏡像・逆順で変わらないことは、交差 4 個までの全状態で確かめた (`tests/test_symmetry.py`)。
* 逆順の yaw が +π なのは、掴むときの手首の向きがリンク番号の向きの接線で決まるため。+π にすると運搬中の回転量が元と同じになり、同じ物理の手になる (平行グリッパーの指が入れ替わるだけ)。

### 学習の前に確かめること

* `scripts/rsl_rl/symmetry_check.py`: (1) 計算し直した観測が環境の観測と一致するか、
  (2) 物理が対称か。まっすぐなロープ (自分自身の鏡像) から、同じ手・鏡像の手・逆順の手を打ち比べ、
  手の後の段の一致とロープの形のずれを、同じ手どうしのずれ (物理の非決定性) と比べる。
